SmartDoc AI – Document Compressor

A Python-based web application that helps users compress PDF documents easily.

🚀 Live Demo

Try the application here:
https://vandana-toppo-smartdoc-ai-app-bsye9b.streamlit.app/

✨ Features

- Upload PDF documents
- Compress PDF files
- Download compressed documents
- Compare original and compressed file sizes

🛠️ Technologies Used

- Python
- Streamlit
- PyMuPDF

👩‍💻 Developer

Vandana Toppo

📌 Project Purpose

SmartDoc AI aims to make PDF compression simple and accessible through a web-based interface.
